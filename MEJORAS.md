# Mejoras futuras (opcionales)

1. **Catálogo con precios** (con lista actualizable, o protegido para que lo vean solo clientes).
2. **Pedidos por WhatsApp con carrito**: el comerciante arma el pedido y se genera un mensaje con cantidades.
3. **Panel para editar sin tocar archivos** (CMS liviano tipo Decap/Sanity) para que el dueño cambie textos y fotos solo.
4. **Galería / mapa de locales que ya venden SANDO** (prueba social para nuevos comerciantes).
5. **Testimonios de comerciantes** con foto del local.
6. **Descarga de ficha técnica en PDF** para que el comerciante la guarde o la comparta.
7. **Cartel/QR para el mostrador** con el link a la web y al WhatsApp.
8. **Estadísticas simples** (por ejemplo Plausible o Umami) para saber cuánta gente abre el link.
9. **Versión en modo "impresión"** de la ficha técnica.
10. **Sección de novedades** (nuevas variedades, promos por temporada).
